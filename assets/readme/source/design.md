# Shanhai Wander README art direction

Audience: People who want to plan a trip without learning travel-planning software.
One-sentence value: Pick a route, arrange each day, keep hotels and charging stops together.
Primary proof: Real desktop captures of the route library, itinerary editor and saved itinerary.
First successful action: Start Docker, open localhost, choose a route and save a private trip.
Visual theme: The application's mountain-road mark, forest green and warm paper.

Palette: paper #f8f8f3 / ink #263b32 / primary #285544 / sand #e7c9a0 / muted #7d857d.
Typography: system sans serif; 66-unit title, 24-unit supporting text, 20-unit route labels.
Shape: 16-unit radius, 2-unit strokes, 8-unit spacing grid.
Motif: a route connecting a scenic stop, overnight stay and charging stop.
Composition: a calm travel journal, with large desktop product screenshots.

The title and itinerary strip are deterministic, project-native SVG, using the existing mountain mark. Screenshots are unretouched browser captures. No generated photography or invented geographic basemap. Desktop acceptance width: 900 CSS pixels, as requested by the user.
