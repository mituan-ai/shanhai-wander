## 当前体验与真实服务边界

本机 Docker 体验地址为 http://127.0.0.1:8000 ，数据存放在项目的 Docker 命名卷中。本地 Python 开发运行使用项目 data 目录，是另一套独立数据。

当前未配置高德凭证。地图 SDK 代理、地点接口及道路响应通过模拟数据测试；尚未使用真实凭证进行在线联调。当前页面提供明确标记的示意图与直线估算。配置三个高德凭证及域名权限后才能启用真实地图、酒店、充电站和道路查询。

HTTPS 的 Caddy 配置已经提供，但未向公网部署或申请证书。酒店没有实时订房接口，充电站没有实时空闲桩或预约接口；相关功能用于行程位置安排和补能建议。

## 重现

运行方法见根目录 README。自动测试：`python manage.py test`。浏览器测试：在测试实例启动后运行 `npm ci`、`npx playwright install --with-deps chromium`、`npm run test:e2e`。

GitHub Actions 配置了 Python 3.12/3.13/3.14 测试、容器启动、备份与浏览器回归；本次没有创建远程仓库或触发线上 CI。
